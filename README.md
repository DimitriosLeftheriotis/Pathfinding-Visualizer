# Pathfinding Visualizer                                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                             
  An interactive 2D grid-based graph traversal and pathfinding visualizer built in Python using **Pygame**. Place start and target nodes, draw custom barrier walls, and watch classic pathfinding algorithms animate in real-time.                                        
                                                                                                                                                                                                                                                                           
  ---                                                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                           
  ## Features                                                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                           
  - **4 Classic Pathfinding & Traversal Algorithms**:                                                                                                                                                                                                                      
    - **A* Search (`A`)**: Informed heuristic search using Manhattan distance ($|x_1 - x_2| + |y_1 - y_2|$), guaranteeing the shortest path with optimal frontier expansion.                                                                                               
    - **Dijkstra's Algorithm (`J`)**: Systematic shortest-path exploration using a priority queue.                                                                                                                                                                         
    - **Breadth-First Search (BFS) (`B`)**: Unweighted level-order traversal guaranteeing the shortest path in uniform grid steps.                                                                                                                                         
    - **Depth-First Search (DFS) (`D`)**: Deep branch traversal exploring along each path until reaching a dead end.                                                                                                                                                       
  - **Interactive Grid (40x40)**:                                                                                                                                                                                                                                          
    - Draw start/end nodes and custom wall barriers with smooth mouse dragging.                                                                                                                                                                                            
    - Right-click eraser to modify or reset individual cells.                                                                                                                                                                                                              
  - **Real-Time State Color Coding**:                                                                                                                                                                                                                                      
    - 🟩 **Green**: Start Node                                                                                                                                                                                                                                             
    - 🟥 **Red**: Target / End Node                                                                                                                                                                                                                                        
    - ⬛ **Black**: Obstacles / Barriers                                                                                                                                                                                                                                   
    - 🟪 **Purple**: Frontier / Open Set (nodes currently queued for evaluation)                                                                                                                                                                                           
    - 🟦 **Blue**: Visited / Closed Set (explored nodes)                                                                                                                                                                                                                   
    - 🟨 **Yellow**: Final Reconstructed Path                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                           
  ---                                                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                           
  ## Quick Start                                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                           
  ### Prerequisites                                                                                                                                                                                                                                                        
  - Python 3.8+                                                                                                                                                                                                                                                            
  - Pygame                                                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                           
  ### Installation                                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                                           
  ```bash                                                                                                                                                                                                                                                                  
  # Clone the repository                                                                                                                                                                                                                                                   
  git clone https://github.com/DimitriosLeftheriotis/Pathfinding-Visualizer.git                                                                                                                                                                                            
  cd Pathfinding-Visualizer                                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                           
  # Install dependencies                                                                                                                                                                                                                                                   
  pip install pygame                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                           
  # Run the visualizer                                                                                                                                                                                                                                                     
  python pathfinding_visualizer.py                                                                                                                                                                                                                                         
  ```

  ## Controls & Keybindings                                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                           
  | Action | Control | Description |                                                                                                                                                                                                                                       
  |---|---|---|                                                                                                                                                                                                                                                            
  | **Left Click (1st)** | Mouse Left Click | Place the **Start Node** (Green) |                                                                                                                                                                                           
  | **Left Click (2nd)** | Mouse Left Click | Place the **Target Node** (Red) |                                                                                                                                                                                            
  | **Left Click & Drag** | Mouse Left Click | Draw **Obstacles / Walls** (Black) |                                                                                                                                                                                        
  | **Right Click** | Mouse Right Click | Erase node / reset cell to default |                                                                                                                                                                                             
  | `A` | Keyboard | Run **A* Search** |                                                                                                                                                                                                                                   
  | `J` | Keyboard | Run **Dijkstra's Algorithm** |                                                                                                                                                                                                                        
  | `B` | Keyboard | Run **Breadth-First Search (BFS)** |                                                                                                                                                                                                                  
  | `D` | Keyboard | Run **Depth-First Search (DFS)** |                                                                                                                                                                                                                    
  | `C` | Keyboard | **Clear & Reset** the entire grid |
